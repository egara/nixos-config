# Proyecto: Quickshell Bar para SicOS

## Objetivo
Implementar una barra de estado dinámica y personalizable para SicOS utilizando QuickShell.

## Progreso Actual

- [x] **Integración con NixOS/Home Manager:** Módulo QuickShell configurado para auto-arranque y reinicios rápidos.
- [x] **Soporte de Theming:** Inyección dinámica de colores y fuentes de Stylix en el QML.
- [x] **Workspace Switcher:** Cambio de escritorio y numeración de workspaces integrada.
- [x] **Menú de Batería:** Popup interactivo con estado de la batería, tiempo restante y control de perfiles de energía (Power Saver, Balanced, Performance).
- [ ] **Monitorización del Sistema:** CPU y RAM en la barra.
- [ ] **Bandeja de Sistema (System Tray):** Añadir iconos de las aplicaciones.
- [ ] **Iconos de Aplicaciones en Workspaces:** (Pendiente de investigación por limitaciones de QuickShell).
